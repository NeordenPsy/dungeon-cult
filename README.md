# Dungeon Cult — открытая мастерская

Отдельные инструменты и скиллы из разработки Dungeon Cult — игры про строительство и управление подземельем.
Это **не исходники игры** и не набор её моделей. Здесь лежат вещи, которые можно использовать в своём проекте.

## Первая штука: локальная 3D-модель по картинке

[Открыть скилл local-image-to-3d](skills/local-image-to-3d/SKILL.md)

Картинка → локальный Pixal3D → проверка в Blender → доработка копии → экспорт GLB.
Без Unreal Engine, игрового кода, подписки на сервис генерации и обязательного рига.
Скилл — инструкция для ИИ-агента с доступом к файлам и локальным программам, а не сама нейросеть.
Его можно читать и как обычный рабочий чек-лист.

В комплекте:

- [запуск Pixal3D и ограничения окружения](skills/local-image-to-3d/references/pixal3d.md);
- [шаблон задачи и пример](skills/local-image-to-3d/references/brief.md);
- [проверка GLB в Blender](skills/local-image-to-3d/scripts/audit_glb.py): треугольники, связные компоненты, открытые и неманифолдные рёбра, UV и текстуры;
- [тесты проверяющего скрипта](tests/test_audit_blender.py).

### Как попробовать

Скачайте репозиторий. Дайте агенту путь к `skills/local-image-to-3d/SKILL.md`, свою картинку и такую задачу:

> Прочитай этот скилл и помоги получить локальную 3D-модель по картинке. Сначала проверь доступные инструменты и видеопамять. Исходники не меняй. Покажи модель со всех сторон, перечисли дефекты. Ничего не отправляй в облако.

Прочитайте [инструкцию запуска](skills/local-image-to-3d/references/pixal3d.md) до установки зависимостей.
Локальное выполнение модели не означает, что сам выбранный вами ИИ-агент работает локально: если важна приватность, не передавайте ему изображения и отчёты через облачный чат.

### Что здесь не обещается

Скилл не устанавливает всю GPU-среду одной кнопкой и не содержит веса моделей.
Генерация требует подходящей NVIDIA/CUDA-среды; первый запуск может скачивать зависимости и веса.
Наш рабочий опыт — Windows + WSL2, RTX 5060 Ti 16 ГБ, 32 ГБ RAM, с отдельными локальными доработками окружения.
Это **не минимальные требования и не гарантия**, что штатная установка поместится в 16 ГБ.

Decimate не заменяет ретопологию. Скрипт проверки не чинит отверстия и не доказывает пригодность для анимации или 3D-печати.
Настоящий осмотр с нескольких сторон остаётся обязательным: счётчик полигонов не обнаружит лишний хвост или сросшиеся пальцы.

## Проверка скрипта

Нужен Blender в PATH (или полный путь к исполняемому файлу). Из корня репозитория:

```sh
blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python tests/test_audit_blender.py
```

Скрипт проверяется в Blender 5.2; другие версии отдельно не подтверждены.
Для своей модели:

```sh
blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python skills/local-image-to-3d/scripts/audit_glb.py -- --input raw.glb --output audit.json
```

В PowerShell перед полным путём к Blender в кавычках поставьте `&`.
Отчёт не перезаписывается: для следующей проверки задайте новое имя.

## Откуда это

Процесс вырос из создания существ для Dungeon Cult. Публичная версия намеренно заканчивается на статической модели: риг, анимации, звуки и интеграция в движок не входят в этот выпуск.
