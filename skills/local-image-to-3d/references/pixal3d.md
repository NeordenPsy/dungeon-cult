Этот хеш описывает проверенную базу CLI, **не полностью воспроизводит наше окружение**: в нём есть отдельная локальная обёртка и настройки памяти.

## Установка

Нужна совместимая NVIDIA/CUDA-среда. Следуй актуальному README Pixal3D для своей ОС и GPU:
там есть зависимости TRELLIS.2, NATTEN и utils3d. Не копируй параметры архитектуры GPU с чужой машины.
Заводи отдельное окружение; не обновляй зависимости уже работающего генератора без необходимости.
Для Windows наш путь — WSL2, а не обещание штатного запуска всего стека напрямую в Windows.

Перед запуском проверь `nvidia-smi`, доступную RAM/VRAM, место под веса и `python inference.py --help`.
Не отключай проверку сертификатов и не используй неподтверждённые зеркала ради установки.
Веса и зависимости имеют собственные условия использования; MIT этого репозитория на них не распространяется.

## Одна проба в уже настроенной среде

Команда выполняется из каталога **upstream Pixal3D**, не из этого репозитория:

```sh
python inference.py --image /path/to/front.png --output /path/to/raw-seed42.glb --seed 42 --low_vram --resolution 1024
```

Это CLI upstream, а не наш установщик. Значение 1024 — разрешение генерации, не число полигонов.
Если файла выхода уже существует, выбери новое имя до запуска: upstream может его перезаписать.
Если стандартный backend внимания недоступен, README upstream описывает вариант `ATTN_BACKEND=sdpa`.
Совместимость остальных расширений всё равно нужно проверить.

Первый запуск может потребовать интернет для загрузки весов и компиляцию GPU-ядер.
«Вычисления локально» и «всё работает без сети» — разные утверждения.
Для офлайн-работы сначала подготовь полный кэш, затем проверь запуск без загрузок;
одного скачивания основных весов может быть недостаточно.

## Почему мы не обещаем готовый запуск на 16 ГБ

В Dungeon Cult использовалась RTX 5060 Ti 16 ГБ и локальная обёртка: выгрузка моделей,
совместное использование DINO, обработка NAF по головам внимания, порциональная нормализация.
Эти изменения нельзя переносить вслепую между версиями библиотек. Обёртка привязана к нашей установке
и в первый публичный выпуск **не включена**. Здесь публикуется процесс и инструмент проверки сетки,
а не переносимый 16-ГБ раннер.

Если штатный low-VRAM режим падает, это не означает, что нужно многократно запускать его заново.
Сохрани ошибку, проверь свободную память и поддерживаемые режимы установленной версии.
Не обещай пользователю, что любая картинка поместится при тех же настройках.

## После генерации

1. Сохрани raw GLB неизменным.
2. Осмотри его в Blender с нескольких сторон; передняя картинка не определяет спину и скрытые поверхности.
3. Запусти `audit_glb.py`, затем при необходимости отдельно обработай копию.
4. Повтори проверку на конечном GLB. После экспорта не должны пропасть текстуры или поменяться ожидаемые единицы.

Скрипт проверки использует импортёр glTF Blender и BMesh. Он не запускает генератор,
ничего не загружает из сети и не обращается к игровому проекту.
